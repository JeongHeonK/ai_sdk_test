# AI SDK v6 Learning Repo

[AI SDK v6](https://ai-sdk.dev) 를 넓게 마스터하기 위한 학습 레포. "AI SDK V6 Crash Course" 목차를 기본 순서로 따라가며, Core / UI / agents / persistence / context engineering / evals / streaming / workflows / advanced patterns 를 균형 있게 익힌다.

## 학습 방식

각 lesson 은 짧고 독립적으로 완료 가능한 단위다. 학습 루프는 **Read → Run → Recall → Connect**:

1. **Read** — 공식 문서에서 필요한 최소 범위만 읽는다.
2. **Run** — 작은 TypeScript 예제로 바로 실행한다.
3. **Recall** — lesson quiz 와 자기 설명으로 회상한다.
4. **Connect** — Core primitive 를 UI, persistence, evals, workflows 로 연결한다.

## 구조

| 경로 | 내용 |
|---|---|
| `MISSION.md` | 학습 목표, 성공 기준, scope/제약 |
| `NOTES.md` | 진행 메모 + 전체 커리큘럼 목차 |
| `RESOURCES.md` | 공식 문서·커뮤니티 등 1차 자료 색인 |
| `lessons/` | 번호순 lesson (HTML, quiz 포함) |
| `reference/` | 개념 지도·치트시트 (HTML) |
| `learning-records/` | 학습 중 확정된 결정·전환 기록 |

## 시작하기

`lessons/0002-how-to-start-the-course.html` 를 브라우저로 열어 학습 루프를 잡은 뒤, `lessons/0001-what-is-ai-sdk.html` 부터 번호순으로 진행한다.
