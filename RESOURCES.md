# AI SDK v6 Resources

## Knowledge

- [AI SDK Introduction](https://ai-sdk.dev/docs/introduction)
  AI SDK의 목적, Core/UI/RSC 구분, provider 표준화의 큰 그림. Use for: 첫 소개와 전체 지도.
- [Generating and Streaming Text](https://ai-sdk.dev/docs/ai-sdk-core/generating-text)
  `generateText`와 `streamText`의 기본 사용법. Use for: 텍스트 생성과 터미널 스트리밍.
- [AI SDK 6 Announcement](https://vercel.com/blog/ai-sdk-6)
  v6 정식 릴리스 발표. Agents framework, tool approval, DevTools, MCP 지원 등. Use for: v6의 방향성과 신규 기능.
- [Migrate AI SDK 5.x to 6.0](https://ai-sdk.dev/docs/migration-guides/migration-guide-6-0)
  v5에서 v6로 바뀐 API와 deprecation. Use for: breaking changes.
- [Generating Structured Data](https://ai-sdk.dev/docs/ai-sdk-core/generating-structured-data)
  v6의 `output` 기반 structured output. Use for: 객체 생성/스트리밍 lesson.
- [Foundations: Tools](https://ai-sdk.dev/docs/foundations/tools)
  tool의 역할, schema, execution model. Use for: agents와 tool calling.
- [Tool Calling Reference](https://ai-sdk.dev/docs/ai-sdk-core/tools-and-tool-calling)
  tool approval, tool results, multi-step flow. Use for: agent loop와 approval.
- [streamText Reference](https://ai-sdk.dev/docs/reference/ai-sdk-core/stream-text)
  `streamText()` 반환값과 스트리밍 세부 API. Use for: terminal/UI streaming.
- [AI SDK Core Reference](https://ai-sdk.dev/docs/reference/ai-sdk-core)
  Core 함수와 타입의 색인. Use for: syntax lookup.

## Wisdom (Communities)

- [Vercel Community: AI SDK](https://community.vercel.com/)
  Vercel 생태계 사용자가 실제 문제를 공유하는 공식 커뮤니티. Use for: migration, deployment, provider-specific issues.
- [GitHub: vercel/ai](https://github.com/vercel/ai)
  AI SDK source, issues, release discussions. Use for: v6 edge cases and implementation details.

## Gaps

- 특정 앱 하나에 종속되지 않는 v6 mastery가 목표이므로, 프레임워크별 Getting Started 문서는 필요한 시점에만 선택적으로 따라간다.
