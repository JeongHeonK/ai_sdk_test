Lesson 0005 / AI SDK Basics

Choosing Your Model & V5→V6 변경점

커리큘럼 01.3(V5→V6 Breaking Changes)과 01.4(Choosing Your Model)를 하나로 묶었다. 두 주제는 결국 "v6에서 모델을 어떻게 고르고 어떻게 연결하느냐"라는 같은 질문의 앞뒤이기 때문이다.

Part A. 모델을 고르고 연결하는 세 경로

lesson 0003~0004에서 본 그대로다. generateText/streamText의 model 인자에 무엇을 넘기느냐가 곧 "어떤 모델을 쓰느냐"다. 방법은 셋이다.

경로코드언제
① AI Gateway 문자열
(v6 기본 global provider)		 model: "anthropic/claude-sonnet-4.5"
import 불필요		 클라우드 모델을 가장 간단히. 여러 provider를 문자열만 바꿔 비교할 때. (유료, AI_GATEWAY_API_KEY)
② 전용 provider 패키지 import { openai } from "@ai-sdk/openai"
model: openai("gpt-5.4")		 그 provider 고유 옵션(safety, reasoning 설정 등)이 필요할 때. 직접 키 관리.
③ OpenAI 호환 provider createOpenAICompatible({ baseURL })
model: lmstudio(modelId)		 LM Studio·자체 호스팅 등 임의 OpenAI 호환 서버. (우리가 쓰는 무료 로컬 경로)
Course anchor: 01. AI SDK Basics -> 3. V5 to V6 Breaking Changes + 4. Choosing Your Model

고를 때 따지는 축

"가장 좋은 모델" 같은 건 없다. 작업에 맞춰 트레이드오프를 잡는다.

  • 능력(capability) — 추론(reasoning), 비전(이미지 입력), tool calling, 긴 컨텍스트 지원 여부. 필요 없는 능력에 돈 쓰지 않는다.
  • 비용 — 토큰당 단가. 분류·요약 같은 단순 작업엔 작은/싼 모델로 충분하다.
  • 지연(latency) — 사용자가 기다리는 UI라면 빠른 모델 + 스트리밍.
  • 로컬 vs 클라우드 — 프라이버시·오프라인·무료가 필요하면 로컬(③). 최고 성능·고급 기능이 필요하면 클라우드(①②).

핵심은, 이 선택이 model 한 줄에 갇혀 있다는 점이다. 나머지 코드(generateText 호출, 결과 처리)는 모델을 바꿔도 그대로다. 그래서 "싼 모델로 개발 → 본번 클라우드 모델로 교체" 같은 전환이 한 줄 수정으로 끝난다.

Part B. V5→V6에서 실제로 바뀐 것 (확정분)

v6는 v5 코드를 대부분 그대로 받지만, 알아둘 변경이 있다. 아래는 공식 6.0 마이그레이션 가이드에서 확인된 항목만 추렸다. 전체 목록은 하단 Primary sources의 가이드를 본다.

1. AI Gateway 문자열이 정식 경로가 됐다

"provider/model" 문자열을 global provider로 바로 쓰는 방식(위 표 ①)이 v6에서 1급 기능이다. 우리가 0003 레슨부터 써온 그 형식이다.

2. 에이전트 클래스 이름·옵션 변경

v5의 Experimental_Agent가 v6에서 ToolLoopAgent로 정식화됐다. 함께 바뀐 두 가지: system → instructions, 그리고 stopWhen이 기본값 stepCountIs(20)을 갖게 됐다(생략 가능). 

// v5
import { Experimental_Agent as Agent, stepCountIs } from "ai";
const agent = new Agent({
  model,
  system: "You are a helpful assistant.",
  tools: { /* ... */ },
  stopWhen: stepCountIs(20), // 직접 지정 필요
});

// v6
import { ToolLoopAgent } from "ai";
const agent = new ToolLoopAgent({
  model,
  instructions: "You are a helpful assistant.", // system → instructions
  tools: { /* ... */ },
  // stopWhen 생략 시 stepCountIs(20)가 기본
});

3. 일부 provider 메타데이터 키 변경

예) Google Vertex provider는 providerOptions/providerMetadata의 키가 google → vertex로 바뀌었다. 쓰는 provider의 가이드를 확인한다.

주의: 이 레슨은 확정된 v6 변경분만 싣는다. maxTokens → maxOutputTokens, ai/react → @ai-sdk/react 등은 v5.0에서 바뀐 것이라 "v5→v6"으로 외우면 헷갈린다. 자기 코드의 시작 버전이 v4 이하라면 v5.0 가이드도 함께 봐야 한다.

직접 해보기: v5 에이전트 코드를 v6로 마이그레이션

아래는 v5 스타일 코드다. v6로 고쳐 써라. 바꿀 곳은 세 군데다 — import, 클래스 이름, 그리고 옵션 하나. (정답이 명확한 comprehension 체크다.) 

// 이걸 v6로 고쳐라
import { Experimental_Agent as Agent, stepCountIs } from "ai";

const agent = new Agent({
  model: "anthropic/claude-sonnet-4.5",
  system: "You are a concise research assistant.",
  tools: { /* ... */ },
  stopWhen: stepCountIs(20),
});

힌트: (1) 어떤 클래스로 바뀌었나? (2) 페르소나를 넣던 옵션 이름은? (3) 기본값이 생겨서 생략 가능해진 옵션은? — 직접 다시 적어 보고, 막히면 위 Part B.2와 비교하라.
