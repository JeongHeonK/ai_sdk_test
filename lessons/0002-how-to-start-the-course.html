Lesson 0002 / AI SDK Basics

How To Start The Course

목표는 AI SDK v6 전체 숙련이다. 시작은 한 프레임워크 튜토리얼을 끝까지 미는 것이 아니라, Core primitive를 작게 실행하고 각 개념을 UI와 agent로 확장하는 방식이 좋다.

오늘 할 일

  1. 0001 - What is the AI SDK?를 5분 안에 읽고 quiz를 푼다.
  2. AI SDK Core Map에서 다섯 primitive 이름을 소리 내어 설명한다.
  3. 공식 Introduction을 열고 Core와 UI의 차이를 한 문장으로 적는다.
  4. 다음 lesson에서 generateText를 실행할 준비를 한다.

학습 루프

1. Read

공식 문서에서 필요한 최소 범위만 읽는다. 한 번에 API reference 전체를 외우지 않는다.

2. Run

작은 TypeScript 예제로 바로 실행한다. 텍스트, 스트림, 객체, tool을 각각 분리해 본다.

3. Recall

lesson quiz와 짧은 자기 설명으로 기억을 꺼낸다. 읽은 느낌이 아니라 회상을 기준으로 삼는다.

4. Connect

Core에서 배운 primitive를 UI, persistence, evals, workflows에 연결한다.

처음 5개 lesson의 순서

  1. What is the AI SDK? provider 차이를 줄이는 공통 TypeScript 계층으로 이해한다.
  2. How To Take This Course 지금 lesson처럼 공부 루프를 고정한다.
  3. V5 to V6 Breaking Changes v6 문서 구조와 바뀐 mental model을 훑는다.
  4. Choosing Your Model provider, model capability, gateway/provider 직접 호출을 구분한다.
  5. Generating Text generateText를 실제로 실행한다.
