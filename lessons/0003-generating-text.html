Lesson 0003 / AI SDK Basics

Generating Text

이번 lesson의 목표는 generateText를 실제로 실행해 보는 것이다. 핵심은 "한 번 호출해 완성된 결과를 받는다"는 것, 그리고 결과가 text 하나가 아니라는 점이다.

한 번에 받는 호출

generateText는 await 한 번으로 모델의 완성된 응답을 받는다. 응답을 토큰 단위로 점진 전달하는 streamText와 대비되는 축이다. 짧은 요약, 분류, 변환처럼 "중간 상태를 보여줄 필요가 없는" 작업에 맞다. 

import { generateText } from "ai";

const result = await generateText({
  model: "anthropic/claude-sonnet-4.5",
  prompt: "Write a one-sentence project update.",
});

console.log(result.text);

결과는 text만이 아니다

반환값은 객체다. 가장 많이 쓰는 셋은 text, usage, finishReason이다. 토큰 사용량과 종료 이유는 비용·디버깅에서 바로 쓰이므로 처음부터 눈에 익혀 두자. 

const { text, usage, finishReason } = await generateText({
  model: "anthropic/claude-sonnet-4.5",
  prompt: "Explain what a vector is in one paragraph.",
});

console.log(text);
console.log(usage);        // { inputTokens, outputTokens, totalTokens }
console.log(finishReason); // "stop" | "length" | "tool-calls" | ...

입력은 세 가지 형태

모델에 무엇을 줄지는 세 가지 방식으로 표현한다.

  • prompt — 단일 문자열. 가장 단순한 일회성 요청.
  • system — 모델의 역할·톤·규칙을 정하는 지시. prompt/messages와 함께 쓴다.
  • messages — user/assistant 턴이 쌓인 대화 배열. 멀티턴에 쓴다.
const { text } = await generateText({
  model: "anthropic/claude-sonnet-4.5",
  system: "You are a professional writer. You write simple, clear, concise content.",
  prompt: `Summarize the following in 3 sentences: ${article}`,
});

실행 준비 (Run)

실제로 돌려 보려면 두 가지가 필요하다.

  1. ai 패키지 설치: npm install ai
  2. AI Gateway 인증 키를 환경변수로 설정: AI_GATEWAY_API_KEY. provider/model 문자열을 쓰면 AI SDK가 Gateway를 통해 모델을 호출한다. 
# .env
AI_GATEWAY_API_KEY=your_api_key_here

# 실행 (Node 20.6+ 기준)
npx tsx --env-file=.env your-file.ts

직접 해보기: system 프롬프트 설계

아래 코드에서 비어 있는 system 문자열을 직접 채워라. 이건 정답이 하나가 아닌 설계 선택이다 — 모델의 역할, 말투, 출력 제약을 어떻게 정하느냐에 따라 같은 prompt라도 결과가 달라진다. 

import { generateText } from "ai";

const { text, usage } = await generateText({
  model: "anthropic/claude-sonnet-4.5",
  // TODO: 모델의 역할과 톤, 출력 형식 제약을 한두 문장으로 정의하라.
  // 예) 어떤 페르소나인가? 길이/형식 제한이 있는가? 무엇을 하면 안 되는가?
  system: "",
  prompt: "Introduce the AI SDK to a backend developer who has never used it.",
});

console.log(text);
console.log(usage);

고려할 점: (1) 페르소나를 좁힐수록 톤이 일관된다. (2) "3문장 이내" 같은 출력 제약은 finishReason/usage에도 영향을 준다. (3) system은 매 호출에 포함되므로 토큰 비용도 생각하라.
