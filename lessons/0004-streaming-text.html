Lesson 0004 / AI SDK Basics

Streaming Text To The Terminal

이번 lesson의 목표는 generateText로 짠 코드를 streamText로 바꿔 토큰이 도착하는 대로 터미널에 출력하는 것이다. 바뀌는 건 함수 하나와 결과를 소비하는 방식뿐이다.

기다리지 않고 흘려보낸다

generateText는 완성된 응답을 한 번에 받는다. 긴 답변일수록 사용자는 첫 글자를 보기까지 오래 기다린다. streamText는 모델이 만드는 즉시 조각(token delta)을 흘려보내, 체감 지연을 크게 줄인다. 챗봇·터미널 출력처럼 "진행 중인 모습"을 보여줘야 하는 작업에 맞다.

핵심 차이: await 위치가 바뀐다

streamText는 호출 자체에 await를 붙이지 않는다. 즉시 result를 반환하고, result.textStream을 for await로 돌면서 조각을 받는다. usage·finishReason·text는 스트림이 끝난 뒤 resolve되는 Promise라, 쓸 때 await한다. 

import { streamText } from "ai";

// await 없음 — 즉시 result를 받는다
const result = streamText({
  model: "anthropic/claude-sonnet-4.5",
  prompt: "Invent a new holiday and describe its traditions.",
});

// 조각이 도착하는 대로 출력 (개행 없이 이어 붙이려면 process.stdout.write)
for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}

// 스트림이 끝난 뒤에야 resolve되는 값들
console.log("\n", await result.usage);
console.log(await result.finishReason);

console.log 대신 process.stdout.write

console.log은 호출마다 개행을 붙인다. 스트림 조각마다 줄이 바뀌면 출력이 깨진다. process.stdout.write(textPart)는 개행 없이 이어 붙여, 한 줄에 글자가 차오르는 "타이핑" 효과를 만든다.

generateText와 같은 점 / 다른 점

  • 같다: model, system, prompt, messages 등 입력 옵션은 동일하다.
  • 같다: 끝나면 text·usage·finishReason을 모두 얻을 수 있다.
  • 다르다: 호출에 await를 붙이지 않는다. 결과를 textStream으로 소비한다.
  • 다르다: 메타데이터는 Promise라 await result.usage처럼 받는다.

실행 준비 (Run)

provider 설정은 lesson 0003과 동일하다. AI Gateway를 쓰면 provider/model 문자열 + AI_GATEWAY_API_KEY, 로컬 LM Studio를 쓰면 @ai-sdk/openai-compatible provider를 그대로 재사용한다. 바뀌는 건 generateText → streamText뿐이다. 

# 실행 (Node 20.6+ 기준)
npx tsx --env-file=.env your-file.ts

직접 해보기: 스트림을 어떻게 소비할지 정하라

아래 for await 루프의 본문을 직접 채워라. 이건 설계 선택이다 — 조각을 그대로 흘려보낼 수도, 모아서 가공할 수도 있다. 

const result = streamText({
  model: lmstudio(modelId),
  prompt: "Write a short poem about streaming data.",
  maxRetries: 1,
});

let charCount = 0;
for await (const textPart of result.textStream) {
  // TODO: 조각이 도착할 때 무엇을 할지 정하라.
  //   - 가장 단순: process.stdout.write(textPart) 로 즉시 출력
  //   - 응용: charCount에 길이를 누적, 또는 특정 단어가 나오면 표시 등
}

console.log("\n--- usage ---", await result.usage);

고려할 점: (1) 즉시 출력은 가장 정직한 스트리밍 데모다. (2) 누적/가공을 넣으면 "흘러오는 데이터를 다룬다"는 감각이 생긴다. (3) 개행을 직접 넣지 않으면 한 줄에 차오른다 — 출력 형태도 선택이다.
