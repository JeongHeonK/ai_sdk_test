Lesson 0001 / AI SDK Basics

What is the AI SDK?

이번 lesson의 목표는 AI SDK를 "모델 호출 라이브러리"가 아니라 AI 앱을 만드는 TypeScript 표준 계층으로 보는 것이다.

핵심 개념

공식 소개 문서는 AI SDK를 React, Next.js, Vue, Svelte, Node.js 등에서 AI 앱과 에이전트를 만들기 위한 TypeScript toolkit으로 설명한다. 중요한 점은 provider마다 다른 호출 방식을 앱 코드에서 직접 떠안지 않게 해 준다는 것이다.

그래서 AI SDK를 배울 때 첫 mental model은 이렇다. 내 앱은 AI SDK의 공통 API를 호출하고, AI SDK가 provider별 차이를 흡수한다.

첫 번째 API 감각

가장 작은 단위는 generateText다. 텍스트를 한 번 생성하고 완료된 결과를 받는다. 스트리밍이 필요하면 같은 축에서 streamText로 넘어간다. 

import { generateText } from "ai";

const { text } = await generateText({
  model: "anthropic/claude-sonnet-4.5",
  prompt: "Write a one-sentence project update.",
});

console.log(text);

위 코드는 provider별 SDK를 직접 다루기보다 AI SDK의 공통 함수에 model과 prompt를 넘기는 형태다. 다음 lesson에서는 이 코드를 실제로 실행할 수 있는 최소 프로젝트 형태로 바꾼다.

"anthropic/claude-sonnet-4.5"처럼 provider/model 문자열을 바로 넘기는 건 v6의 AI Gateway 글로벌 provider 기능이다. 모델 버전 숫자는 시점에 따라 바뀌므로 (예: 더 최신 Sonnet) 항상 최신 모델명은 공식 문서에서 확인한다.
