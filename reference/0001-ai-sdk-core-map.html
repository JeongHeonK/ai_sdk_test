AI SDK Core Map

AI SDK는 provider 차이를 가리는 TypeScript 계층이다. 가장 먼저 익힐 축은 generateText, streamText, structured output(output 옵션), tools, UI message streams다.

Core primitives

Primitive Use when First question
generateText 완성된 텍스트나 structured output이 필요할 때 응답 전체를 기다려도 되는가?
streamText 터미널, HTTP, UI로 점진적 응답을 보내야 할 때 중간 상태를 사용자에게 보여줄 것인가?
structured output 객체, 배열, enum 같은 구조화된 결과가 필요할 때 schema로 결과 형태를 검증해야 하는가?
tools 모델이 코드, DB, API, MCP 서버를 호출해야 할 때 모델 혼자 답하면 안 되고 외부 행동이 필요한가?
UI messages 프론트엔드 채팅 상태, tool state, metadata를 다룰 때 사용자에게 어떤 message part를 보여줄 것인가?

참고: structured output은 별도 함수가 아니라 generateText/streamText의 output 옵션이다. import { Output } from "ai" 후 output: Output.object({ schema }) 형태로 schema를 넘기고 결과는 result.output에서 받는다.
